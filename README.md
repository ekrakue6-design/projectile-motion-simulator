
# Projectile Motion Simulator 🚀

## Overview
A Python-based physics simulator that calculates
the motion of a projectile under gravity.

## Objectives
- Calculate flight time.
- Determine maximum height.
- Calculate horizontal range.
- Apply projectile motion equations.

## Technologies
- Python
- Math library

## Physics Concepts
- Kinematics
- Trigonometry
- Projectile motion

## Future Improvements
- Add trajectory visualization.
- Add user-friendly graphical interface.
- Include air resistance.
